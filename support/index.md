## GitHub Issues

Use GitHub Issues for:

- reproducible bugs
- feature requests
- documentation improvements

When reporting a problem, include your Roku model, Roku OS version, Immich version, companion version, and whether the issue is in the companion app, channel, or screensaver. The companion version appears below **Help &amp; setup** in the companion's navigation.

Use **Copy as Markdown** above a guide's heading to copy its text into a support conversation or an assistant. The [Markdown documentation index](<https://immich-lounge.github.io/llms.txt>) links to the exported setup and help pages.
